This is a list of modules with their support-status for CSB. It only contains modules which modify the behavior of
sheets, tokens, and such (possible conflict with CSB-functionality). Modules which are modifying other parts of Foundry
should generally work if there are no dependencies for other systems.

- Dice So Nice!
- Chat Commander
- [Status Icon Counters](https://foundryvtt.com/packages/statuscounter/)
- [DFreds Convenient Effects](https://foundryvtt.com/packages/dfreds-convenient-effects)
