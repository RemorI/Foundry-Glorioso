# Use your own CSS

You can customize your sheets with your own CSS. You can add a CSS file in the system configuration. The path must lead to a CSS file, starting from Foundry's Data Directory.

Components have various classes, depending on the component type and component's key, to help you target the right components in your configuration.

If you don't know CSS, and would like to learn, you can head over to [the W3C CSS tutorial](https://www.w3schools.com/css/) which is quite complete on this subject.
