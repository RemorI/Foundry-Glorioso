# Custom System Builder

Build your custom system without any line of code!

## Introduction

This system is intended to easily build sheets in FoundryVTT with dynamic display and roll capabilities, in a game agnostic way.

[The documentation is available here](https://gitlab.com/custom-system-builder/custom-system-builder/-/wikis/home). It contains guidelines, tips & tricks and some other stuff. It's worth a visit.

If you need an Example to help you to get started with this system, [you can find it here](https://foundryvtt.com/packages/custom-system-builder-example) and download it as a module.

If you have any issues, requests or questions, [please report them here](https://gitlab.com/custom-system-builder/custom-system-builder/-/issues/new). You can also ask on the [FoundryVTT Discord](https://discord.gg/foundryvtt) ([Official CSB Channel](https://discord.com/channels/170995199584108546/1037072885044477962)), we are `@LinkedFluuuush [CSB Creator]` and `@Martin1522 [CSB Dev]`!

For an up-to-date Roadmap, please visit [ROADMAP.md](https://gitlab.com/custom-system-builder/custom-system-builder/-/blob/develop/ROADMAP.md) on the develop branch.

If you want to contribute to the project, please see [CONTRIBUTING.md](https://gitlab.com/custom-system-builder/custom-system-builder/-/blob/main/CONTRIBUTING.md).

If you seek to extend the system or use it in macros, you can [visit the API](https://custom-system-builder.gitlab.io/custom-system-builder/).

If you like this system and want to support me, you can [buy me a coffee](https://ko-fi.com/linkedfluuuush) ! You can also send us kind words through the Discord channel or by creating an issue, they are always appreciated !

## How to install the system

You can install the latest released version of the system by using the package manager in your FoundryVTT server! Alternatively, you can use this manifest link to install the system : `https://gitlab.com/custom-system-builder/custom-system-builder/-/raw/main/system.json`.

If you want to test the next version ahead of time, you can have access to the beta version with this manifest link : `https://gitlab.com/api/v4/projects/31995966/jobs/artifacts/beta/raw/out/system.json?job=build-beta`. The specific doc for the beta version is available here : [Beta Wiki](https://gitlab.com/custom-system-builder/custom-system-builder/-/wikis/beta/home)

If you want to switch an existing world to the beta version, you can [follow this guide !](https://gitlab.com/custom-system-builder/custom-system-builder/-/wikis/Guides/Switch-to-Beta)

> &#x26a0;&#xfe0f; **Unstable version**
>
> Lastly, if you want to see the latest changes, at the risk of breaking your games, you can have access to the unstable version with this manifest link : `https://gitlab.com/api/v4/projects/31995966/jobs/artifacts/develop/raw/out/system.json?job=build-unstable`.
>
> Be aware that this version reflects the latest code in this repository, and thus can contain untested development, or breaking code. Please back-up your games regularly if you plan to use this version!
